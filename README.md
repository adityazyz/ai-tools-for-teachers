# EduVetta

AI tools for teachers to simplify everyday teaching tasks.

EduVetta helps teachers create and manage:

- AI-generated question papers
- AI-generated assignments
- Interactive quiz games
- Recorded lectures and digital board lessons
- Lecture summaries and board notes
- Student submissions and grading

## Website

[Visit EduVetta](https://eduvetta.com/)

## Features

### AI Question Paper Generator

Create question papers from a topic, YouTube video, PDF, Word document, or voice prompt. Choose question types, marks and question counts, review the generated paper, and share it with students.

[Explore the AI Question Paper Generator](https://eduvetta.com/features/ai-question-paper-generator)

### AI Assignment Generator

Create assignments from a topic, video, document, or voice instruction. Share one link with students, collect written answers and file attachments, review submissions, check for similar work, and export results to Excel.

[Explore the AI Assignment Generator](https://eduvetta.com/features/ai-assignment-generator)

### AI Quiz Game Generator

Turn topics, PDFs, YouTube lessons, or your own questions into interactive browser-based quiz games. Students can play without creating an account, while teachers can set participant limits and review scores.

[Explore the AI Quiz Game Generator](https://eduvetta.com/features/ai-quiz-game-generator)

### Lecture Recording & Digital Board

Teach using a digital board or record a lecture. Save board notes as PDFs, create structured lecture summaries from a voice recap, and send lectures and notes directly to your batch's Telegram channel.

[Explore Lecture Recording & Digital Board](https://eduvetta.com/features/lecture-recording-and-digital-board)
